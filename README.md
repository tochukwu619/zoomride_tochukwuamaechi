## Message to Manager

My recommendation to the manager of ZoomRide is to invest more in Lagos, Accra, and Abuja. The most revenue is generated by Lagos (N218,890), but the highest average fare is from Accra (N2,807.27). I identified poor data quality issues from inconsistencies in the city entries and duplicate values in the trip record. If I didn't fix these issues before my analysis, it would misrepresent the metrics for the city values and skew the revenue generated. Before making a big decision, 9 of the completed rides have missing fares, and this can have an impact on the revenue; hence, I will recommend identifying the values to measure the impact.
